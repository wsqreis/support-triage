# Importing notes from other apps

Go to **Settings → Data → Import**. Noteflow imports:

- **Markdown** files and folders (folders become notebooks)
- **Evernote** exports (.enex), including tags and attachments
- **Plain text** files

Imports of up to 5,000 notes run in the background; you will get a notification when they finish. Formatting that Noteflow does not support, such as complex tables from Evernote, is converted to plain text.
