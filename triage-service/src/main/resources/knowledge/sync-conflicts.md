# Duplicate notes and sync conflicts

When the same note is edited on two devices while one of them is offline, Noteflow keeps both versions instead of choosing one. The second version appears next to the original with **(conflict)** in its title.

Open both, keep the content you want, and delete the copy you do not need. Nothing is lost: both versions are full copies.

To avoid conflicts, let a device finish syncing (the sync icon stops spinning) before editing the same note elsewhere.
